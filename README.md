# EmpowerTours.xyz

Portfolio website for EmpowerTours - a Web3 development agency building on Monad.

## Projects

- **Monad Odyssey** - 3D galaxy visualization of the Monad ecosystem
- **EmpowerTours Bot** - Telegram bot for rock climbing adventures & $TOURS tokens
- **Empower MiniApp** - Farcaster Mini App for Travel Passports & Music NFTs

## Run Locally

```bash
npm install
npm run dev
```
